## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Agent 64: Spies Never Die**. An offline trainer for the single-player campaign that provides adjustable health, ammunition, reload, movement, accuracy, and mission-assistance options. It is designed for experimenting with objective-based missions, modding terminals, stealing secret plans, rescuing hostages, and surviving firefights across the game's varied locations.

**Target Audience:** Players who want to replay campaign missions with relaxed difficulty, test alternative approaches to objectives, practice weapon handling, explore mission environments, or experiment with custom challenge setups without affecting competitive multiplayer.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Use the movement options to adjust traversal speed and jump height while exploring mission spaces such as skyscrapers, nightclubs, museums, catacombs, and snow bases. Disable movement modifiers before scripted sequences or objective transitions if the mission behaves unexpectedly.

### Tools & Inventory

The trainer works with the weapons and ammunition carried during a mission. Enable unlimited ammo or no reload after entering a mission, then switch weapons normally through the game's standard controls. Reapplying a weapon or ammunition option after changing equipment can refresh the trainer state.

### World & Environment

Agent 64 missions use self-contained environments with varied objectives, hidden routes, and higher-difficulty areas. Use Objective Assist and Mission Timer Freeze for practice runs involving terminal modding, secret-plan recovery, civilian rescues, and other mission tasks. Save the game normally and avoid changing trainer settings during loading screens.

### Combat & Weapons

Activate health, armor, ammunition, and accuracy options before engaging armed guards. No Reload and Rapid Fire are useful for testing weapon behavior and clearing large firefights, while Steady Aim supports controlled shots. Return all combat options to their default state before leaving the campaign and entering any multiplayer mode.
